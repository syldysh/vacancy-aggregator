## О проекте

Я развиваю этот проект, чтобы данные о рынке труда было удобнее изучать. Приложение получает вакансии через открытый API портала [«Работа России»](https://trudvsem.ru/), сохраняет их в PostgreSQL и показывает в простом веб-интерфейсе.

Пользователь может не просматривать вакансии по одной, а искать по всем собранным данным, сочетать несколько фильтров, сравнивать зарплаты и переходить на страницу исходной вакансии. Для меня этот проект также стал возможностью на практике разобраться, как устроено полноценное веб-приложение: от внешнего API и миграций базы данных до REST-эндпоинтов и интерфейса в браузере.

## Как это работает

```text
API «Работа России»  →  Spring Boot  →  PostgreSQL  →  REST API  →  Веб-интерфейс
```

При запуске приложение запрашивает первую страницу вакансий из источника. Дополнительные страницы можно загрузить через интерфейс. Перед сохранением приложение проверяет ссылку и источник вакансии, чтобы не создавать дубликаты.

## Основные возможности

- Загрузка вакансий из публичного API «Работа России»
- Выбор количества загружаемых страниц от 1 до 100
- Автоматическая загрузка первой страницы при запуске приложения
- Поиск по названию, описанию и требованиям вакансии
- Фильтрация по городу, компании и диапазону зарплаты
- Сортировка по дате публикации и зарплате
- Подробный просмотр описания, требований и ссылки на исходную вакансию
- Статистика по текущей выборке: количество вакансий, городов и компаний
- Хранение данных в PostgreSQL
- Управление схемой базы данных через Liquibase
- REST API для вакансий, фильтров и загрузки данных
- Автоматические тесты для контроллеров, сервисов, репозиториев и модели данных

## Локальный запуск

### Требования

- Java 21 или новее
- Docker с Docker Compose

### 1. Клонировать репозиторий

```bash
git clone https://github.com/syldysh/vacancy-aggregator.git
cd vacancy-aggregator/project
```

### 2. Запустить PostgreSQL

```bash
docker compose up -d
```

Готовый Compose-файл запускает PostgreSQL на порте `5432`. Параметры базы данных уже совпадают с настройками в `application.properties`, поэтому для локального запуска дополнительная конфигурация не нужна.

### 3. Запустить приложение

На macOS или Linux:

```bash
sh gradlew bootRun
```

На Windows:

```powershell
gradlew.bat bootRun
```

После запуска нужно открыть [http://localhost:8080](http://localhost:8080) в браузере. Первая загрузка данных может занять немного времени.

### 4. Остановить базу данных

```bash
docker compose down
```

## Запуск тестов

Из папки `project`:

```bash
sh gradlew test
```

В тестовом окружении используется база данных H2 в памяти, поэтому PostgreSQL для этой команды не нужен.

## REST API

| Метод | Эндпоинт | Назначение |
| --- | --- | --- |
| `GET` | `/api/vacancies` | Получить все сохранённые вакансии |
| `GET` | `/api/vacancies/{id}` | Получить вакансию по ID |
| `GET` | `/api/vacancies/search` | Найти и отфильтровать вакансии |
| `GET` | `/api/cities` | Получить список городов |
| `GET` | `/api/companies` | Получить список компаний |
| `POST` | `/api/parse-vacancies?pages=1` | Загрузить новые вакансии из источника |

Для поиска можно передать необязательные параметры `city`, `company`, `keyword`, `salaryFrom` и `salaryTo`.

## Практический опыт

Этот проект помог мне разобраться в работе с внешним API, преобразовании JSON-данных в Java-объекты, проектировании модели базы данных, написании поисковых запросов и разделении Spring-приложения на контроллеры, сервисы и репозитории. Я также добавила интеграционные и модульные тесты для проверки основных частей приложения.

Данные о вакансиях принадлежат их исходным поставщикам и доступны через публичный API портала «Работа России». Этот репозиторий является учебным проектом.
