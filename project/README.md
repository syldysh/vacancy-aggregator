# Агрегатор вакансий

Веб-приложение для сбора и анализа вакансий с различных источников. Приложение автоматически собирает данные о вакансиях, предоставляет удобный интерфейс для поиска и фильтрации, а также аналитику по рынку труда.

## Функциональность

### Поиск и фильтрация
- Поиск вакансий по городу, компании и ключевым словам
- Фильтрация по диапазону зарплаты (от-до)
- Сортировка по дате публикации (от последних / до давних)
- Сортировка по зарплате (по возрастанию/убыванию)
- Выбор конкретных регионов из списка
- Фильтрация по компаниям

### Отображение данных
- Удобное отображение в виде таблицы с возможностью сортировки по любому столбцу
- Детальная информация о каждой вакансии
- Статистика по загруженным данным:
  - Количество загруженных городов
  - Количество вакансий по городам
  - Количество отразившихся компаний 
  

### Автоматизация
- Автоматическое обновление данных с источников
- Возможность обновления по страницам

## Технический стек

- **Backend**: 
  - Java 21
  - Spring Boot 3.5.0
  - Spring Data JPA
  - PostgreSQL

- **Frontend**:

## Инструкция по запуску

1. Проект можно запустить, скачав ZIP-архив project:
   - Если вы скачали:
     - Распакуйте архив
     - Откройте архив в IntelliJ IDEA
     - Откройте docker и введите в терминал в IntelliJ IDEA
     ```
     docker-compose up -d 
     ```
     - Далее запустите HseApplication (по адресу)
     ```
     /hse/src/main/java/ru/goyda/hse/HseApplication.java
     ```

2. Проверка работоспособности
   1. Откройте браузер
   2. Перейдите по адресу: http://localhost:8080
   3. Вы должны увидеть главную страницу приложения со списком вакансий

3. Запуск через терминал (альтернативный способ):
   ```bash
   # Перейдите в директорию проекта
   cd путь/к/вашему/проекту

   # Соберите проект
   ./gradlew build

   # Запустите приложение
   ./gradlew bootRun
   ```

4. Настройка базы данных (если не используется Docker):
   ```bash
   # Подключитесь к PostgreSQL
   psql -U postgres

   # Создайте базу данных и пользователя
   CREATE DATABASE vacancy_db;
   CREATE USER vacancy_user WITH PASSWORD 'your_password';
   GRANT ALL PRIVILEGES ON DATABASE vacancy_db TO vacancy_user;
   ```

5. Настройка конфигурации:
   - Откройте файл `src/main/resources/application.properties`
   - Проверьте настройки подключения к базе данных:
   ```properties
   spring.datasource.url=jdbc:postgresql://localhost:8080/vacancy_db
   spring.datasource.username=vacancy_user
   spring.datasource.password=your_password
   ```

## Парсинг вакансий

Приложение автоматически собирает данные о вакансиях с trudvsem.ru. Парсинг происходит:
- При запуске приложения
- По запросу через API

### Обрабатываемые поля:
- Название вакансии
- Компания
- Город
- Зарплата
- Описание
- Требования
- Дата публикации
- Ссылка на вакансию

## Мониторинг и логирование

- Логи приложения доступны в `logs/application.log`
- Уровень логирования настраивается в `application.properties`
